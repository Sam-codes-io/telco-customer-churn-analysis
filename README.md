# 📊 Telco Customer Churn Analysis

## 📌 Project Overview
This project analyzes customer churn data to identify patterns and key drivers of customer attrition.

## 🎯 Objective
- Identify high-risk churn segments
- Analyze contract impact on churn
- Provide business recommendations

## 🛠 Tools Used
- SQL (MySQL)
- Power BI
- Excel

## 📊 Dashboard Insights
- Month-to-month contract customers have highest churn
- Customers with higher monthly charges churn more
- Short tenure customers are more likely to churn

## 💡 Business Recommendations
- Offer discounts for yearly contracts
- Provide loyalty programs
- Target high monthly charge customers with retention offers
